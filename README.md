# Sprint 4 Project - Мультимодальная нейросеть для определения калорийности блюда по его описанию и фотографии
Проект реализуется в рамках 4-ого спринта обучения на курсе "Инженер по глубокому обучению нейросетей" (Яндекс Практикум)

Создаваемая нейросеть, должна определять калорийность блюд.
Модель обучается на датасете с фотографиями тарелок с разными блюдами и текстовым описанием их ингредиентного состава.

## Датасет
[Датасет (1.3 ГБ)](https://disk.yandex.ru/d/kz9g5msVqtahiw), содержит фотографии блюд, описание ингредиентов, а также общую массу порции и калорийность
- `data/ingredients.csv` 
    - `id`, `ingr` - названия ингредиентов
- `data/dish.csv` 
    - `dish_id`
    - `total_calories` - общее число калорий - целевая переменная
    - `ingredients` - список всех `Id` ингредиентов в формате `ingr_0000000122;ingr_0000000026;..`
    - `split` - данные уже разбиты на `train/test`
    - `total_mass`, `total_calories`
- `data/images` - фотографии блюд, директория соответствует `dish_id

## Настройка виртуального окружения

В качестве менеджера окружения используется **uv**, среда **Python 3.10**.

 Install uv
```bash
# Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

### Создание virtual environment (Python 3.10)

```bash
uv venv --python 3.10
```

Будет создана директория `.venv`

### Активация venv

```bash
source .venv/bin/activate
```
Большинство `uv` команд (`uv run ...`) работают без ручной активации.

### Установка зависимостей

Зависимости перечислены в `sprint4_requirements.txt` (https://code.s3.yandex.net/deep-learning/sprint4_requirements(1).txt)

При работе на ВМ с GPU:
```bash
uv add -r sprint4_requirements.txt
```

При работе без ВМ с GPU (на локальном компьютере) отключаем лишние зависимости:
```bash
uv add -r sprint4_requirements_no_gpu.txt

## Структура директорий проекта

- `\data` - данные датасета
    - `\images` - исходные (сырые данные) - директория с изображениями блюд датасета 
        - `\<dish_id>` - директория с изображением конкретного блюда с id = <dish_id>
            - `rgb.png` - фото блюда
    - `dish.csv` - исходные (сырые данные) - описание блюд
    - `ingredients.csv` - исходные (сырые данные) - названия ингредиентов
    - `meal_cleaned.csv` - очищенный развернутый по ингредиентам датасет блюд без "deprecated" ингредиентов
    - `meal_combined.csv` - датасет сырых блюд и ингредиентов в сводном виде (блюда + названия ингредиентов)
    - `meal_combined_cleaned.csv` - результат предобработки - очищенный датасет блюд и ингредиентов в сводном виде (блюда + названия ингредиентов)
    - `\usda` 
        - `usda_nutrient_values.csv` - сырая выгрузка калорийности продуктов из документа USDA "FNDDS Nutrient Values.xlsx" - рабочий вариант (csv) для возможности обработки
    - `\nutrients`
        - `\raw`
            - `ingr_nutr_mapping_raw.csv` - результат первчиного сырого сопоставления через прямой поиск (датасет сохраненный в csv)
            - `ingr_nutr_mapping_raw.xlsx` - результат первчиного сырого сопоставления через прямой поиск (конвертация в excel-файл для дальнейшей ручной обработки)
        - `\processed`
            - `ingr_nutr_mapping_processed.xlsx` - итоговый результат маппинга, включая поиск информации и обогащение вручную, по тем ингредиентам, которые не были состыкованы прямым соответствием (мастер excel)
            - `ingr_nutr_mapping_processed.csv` - итоговый результат маппинга, включая поиск информации и обогащение вручную, по тем ингредиентам, которые не были состыкованы прямым соответствием (рабочий csv)
            - `ingr_nutr_mapping_result.csv` - финальные очищенные данные маппинга для использования при выполнении экспериментов
    - `\preprocess` 
        - `text_emb.pt` - подготовленные эмбеддинги названий ингредиентов для 2-ого блока экспериментов
    - `\model`
        - `\experiment-<num_exp>` - сохраненная лучшая модель и данные обучения эксперимента <num_exp>
    

- `scripts` - код обучения и работы с данными
    - `img_util.py` - утилиты для показа картинки блюда
    - `text_utils.py` - утилиты для преобразования и очистки текстовых названий ингредиентов
    - `v1_fusi0n_not_actual` - код для первого блока экспериментов - не валидный
        - `config.py` - главный конфигурационный файл для всех настроек модели и экспериментов
        - `dataset.py` - torch.Dataset и collate_fn для передачи данных в модель
        - `models.py` - модель нейросети (архитектура и логика)
        - `utils.py` - утилиты для выполнения обучения и валидации
    - `v2_attention` - код для использования во 2-м блоке экспериментов с новой архитектурой - финальный вариант
        - `config.py` - главный конфигурационный файл для всех настроек модели и экспериментов
        - `ingr2embed.py` - подготовка эмбеддингов текстового описания ингредиентов
        - `dataset.py` - torch.Dataset и collate_fn для передачи данных в модель
        - `models.py` - модель нейросети (архитектура и логика)
        - `utils.py` - утилиты для выполнения обучения и валидации
        

- `notebook.ipynb` - основной ноутбук с выполнением EDA и проведением экспериментов 
- `usda_food_processing.ipynb` - ноутбук с выполнением маппинга внешнего справочников калорийности продуктов (на базе USDA)
- `project_exp_v2.ipynb` - ноутбук с выполнением эксприментов блока 2 на новой (целевой) архитектуре модели
- `project_exp_v1.ipynb` - ноутбук с выполнением эксприментов блока 1 на старой (неактуальной) архитектуре модели
- `project_vm_gpu.ipynb` - ноутбук с выполнением эксприментов на ВМ с GPU от Яндекс.Практикум
- `project_exp_v2_colab.ipynb` - ноутбук с выполнением эксприментов на ВМ с GPU в среде Google Colab

- `sprint4_requirements.txt` - необходимые библиотеки для окружения
- `sprint4_requirements_no_gpu.txt` - необходимые библиотеки для окружения без GPU
